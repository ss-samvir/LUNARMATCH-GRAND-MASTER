Why these algorithms?

01
FEATURE DETECTION

SIFT

Scale-Invariant Feature Transform identifies distinctive local structures while providing descriptors designed to remain useful under scale and orientation changes.

FEATURES Up to 5,000
CONTRAST 0.018
EDGE 10
02
DESCRIPTOR

LOCAL DESCRIPTORS

SIFT descriptors represent local image structure numerically so that candidate correspondences can be compared rather than judged by visual appearance alone.

REPRESENTATION Numerical
COMPARISON L2 DISTANCE
03
MATCHING

BF / L2

Brute-force descriptor matching compares candidate descriptors directly using Euclidean distance. The implementation then applies a Lowe ratio criterion and reciprocal consistency check.

DISTANCE EUCLIDEAN
RATIO 0.76
FILTER RECIPROCAL
04
GEOMETRIC VERIFICATION

RANSAC

Random Sample Consensus estimates a geometric relationship while rejecting correspondences that do not agree with the dominant transformation.

MODEL HOMOGRAPHY
THRESHOLD 5 px
PURPOSE OUTLIER REJECTION
DESIGN DECISION

Why not simply use an LLM?

LUNARMATCH

Measurable image evidence

  • Detects local visual features.
  • Produces numerical descriptors.
  • Measures candidate correspondences.
  • Applies geometric verification.
  • Exposes inliers and outliers.
  • Can preserve machine-readable metadata.
VS
GENERAL LLM

Semantic reasoning

  • Excellent for language and explanation.
  • Useful for documentation and interpretation.
  • Not inherently a calibrated image correspondence engine.
  • Does not replace geometric verification.
  • Cannot manufacture ground truth from an unsupported image.
DESIGN PRINCIPLE

LunarMatch uses deterministic computer-vision measurements for correspondence and can use higher-level AI systems as complementary tools for explanation, assistance or future extensions. The two roles should not be conflated.

INTEROPERABILITY

Standards & data language.

OGC

Open Geospatial Consortium

OGC develops open standards for geospatial information and services. A production LunarMatch ecosystem can use compatible geospatial standards to exchange imagery, coordinates and spatial reference information.

ROLE GEOSPATIAL INTEROPERABILITY
CRS

Coordinate Reference System

Coordinates have meaning only within an appropriate reference system. LunarMatch therefore reports CRS, projection and datum information when it is available.

ROLE SPATIAL CONTEXT
GEO

Geospatial Metadata

Acquisition information, image identifiers, instrument names and coordinate information can provide evidence beyond pixel-level matching.

ROLE SOURCE VALIDATION
SCIENTIFIC VALIDATION

Correspondence is only one layer.

The platform keeps image-level evidence separate from mission-level evidence. This prevents a mathematically strong image match from being incorrectly presented as absolute geographic truth.

OHRC Instrument evidence Requires supporting metadata/reference evidence.
