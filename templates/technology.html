```
DESIGN CHOICE

Why computer vision instead of an LLM?

The central problem is geometric image correspondence. It requires measurable relationships between image features, not natural-language interpretation.

LUNARMATCH therefore uses deterministic computer-vision operations for the correspondence pipeline and reserves language-based explanation for the human-facing interface.

TASK LUNARMATCH APPROACH
Feature detection SIFT
Descriptor comparison BF / L2
Match filtering Lowe ratio + reciprocal check
Geometric verification Homography + RANSAC
Scientific validation Metadata / reference evidence
```

```
STAGE 04

Matching is filtered twice.

A descriptor being close to another descriptor is not sufficient. LUNARMATCH applies multiple consistency checks before geometric verification.
```

```
GEOMETRIC CONSISTENCY
STAGE 05

RANSAC asks whether the matches agree.

Descriptor similarity can contain false positives. RANSAC estimates a geometric transformation from candidate correspondences while rejecting points that do not agree with the model.

CURRENT CONFIGURATION RANSAC THRESHOLD · 5 PX

The resulting inlier set provides a stronger geometric indicator than raw descriptor matches alone.
```

```
GEOSPATIAL INTEROPERABILITY

Where do CRS and OGC fit?

Spatial metadata is useful only when the image or reference source actually provides it. The system therefore reports spatial-reference information rather than assuming it.

CRS

Coordinate Reference System

Defines how spatial coordinates are represented and interpreted.

OGC

Open Geospatial Consortium

Provides widely used geospatial standards and interfaces. LUNARMATCH treats OGC terminology as an interoperability context rather than claiming certification.

GEO

Projection + Datum

Additional spatial-reference information can determine how reported coordinates should be interpreted.

IMPORTANT OGC terminology does not by itself prove that an image has valid coordinates.
```

```
TECHNICAL LIMITATION

What the engine does not claim.

A high correspondence score does not independently prove lunar coordinates, mission identity or ground-truth accuracy. Those claims require supporting metadata, calibration or independent reference information.
```
