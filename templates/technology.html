05 · TECHNOLOGY

Under the hood.

Current V2 engine

SIFT feature detection and description → BFMatcher → Lowe's ratio test → reciprocal matching → RANSAC homography verification. The resulting score is a deterministic correspondence/reliability indicator, not a trained-model probability.


Interoperability

V2 is designed to become standards-aware for planetary/geospatial imagery, with CRS/projection/datum fields preserved rather than guessed.

Future standards

OGC and relevant planetary data conventions will be integrated only where technically appropriate and documented.

Architecture

Flask API · OpenCV · SQLite · browser UI · result persistence.
