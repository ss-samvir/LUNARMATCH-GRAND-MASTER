03 · VALIDATION

Ground Truth Lab

A future-ready validation layer for known correspondences, coordinate evidence and benchmark datasets.

Ground-truth pairs

Maintain reference image pairs with known corresponding regions and coordinates.

Metrics

Precision, recall, false-match rate, localization error, verified-match rate and processing time.

Metadata evidence

Display latitude/longitude, altitude, acquisition time, CRS, projection, datum, mission and instrument when supplied by the source.


Scientific rule

Coordinates are never fabricated. If an image does not contain usable geospatial metadata or an explicit reference sidecar, LunarMatch reports “Not available”. A correspondence score is not presented as ground-truth accuracy.
