EVIDENCE & VALIDATION

Don't just match. Verify.

LUNARMATCH separates computational correspondence from metadata and reference evidence so users can understand exactly what a result establishes—and what it does not.

◎
CORE PRINCIPLE

Evidence must come from the data.

A visually strong correspondence does not automatically establish a mission, instrument, geographic coordinate or lunar location. Those claims require independent supporting evidence.

EVIDENCE MODEL

Three layers of verification.

01 COMPUTATIONAL
IMAGE EVIDENCE

Correspondence

Measures whether local visual features between the two observations produce consistent candidate matches.

  • SIFT feature extraction
  • Descriptor matching
  • Lowe ratio filtering
  • Reciprocal matching
  • Homography estimation
  • RANSAC inlier verification
02 METADATA
FILE EVIDENCE

Provenance

Examines information embedded in the supplied image file rather than attempting to infer unsupported information from visual appearance.

  • Latitude / longitude
  • Acquisition time
  • Camera information
  • Mission information
  • Instrument information
  • Projection / CRS information
03 REFERENCE
EXTERNAL EVIDENCE

Ground Truth

Independent mission or reference information can provide stronger validation when a trusted reference source is available.

  • Reference image identity
  • Known coordinates
  • Mission archive information
  • Instrument provenance
  • Calibrated map information
  • Independent ground truth

CHANDRAYAAN CONTEXT

Instrument identities must be evidenced.

LUNARMATCH can recognize instrument names from supported metadata. Visual appearance alone is not treated as proof of instrument identity.

OHRC
◉

Orbiter High Resolution Camera

A high-resolution imaging instrument associated with Chandrayaan-2. LUNARMATCH reports OHRC only when the supplied evidence supports that identity.

TMC
◇

Terrain Mapping Camera

A terrain-mapping imaging instrument associated with Chandrayaan-2. Instrument identity is not inferred solely from image appearance.

IIRS
⟡

Imaging Infrared Spectrometer

An imaging spectrometer associated with Chandrayaan-2. LUNARMATCH treats its identity as established only when supported by metadata or reference evidence.

◎
COORDINATE POLICY

Exact coordinates only when available.

If genuine latitude and longitude metadata are present, LUNARMATCH can display them. If they are absent, the platform reports that localization is unavailable rather than generating an estimated coordinate.

Current limitation

The current correspondence engine does not perform calibrated pixel-to-lunar-coordinate localization or independently query a mission reference catalogue.

GEOSPATIAL INTEROPERABILITY

Standards should be claimed only when implemented.

Geospatial standards such as OGC specifications can provide important interoperability concepts for planetary data. However, LUNARMATCH does not claim formal OGC certification or compliance unless a specific implemented standard has been tested and documented.

About the “IRC” reference

If a specific standard or requirement is referred to as “IRC”, its exact expansion and specification must first be identified before the platform claims compliance.

SCIENTIFIC INTERPRETATION

LUNARMATCH provides computational correspondence evidence and metadata-aware validation. A strong correspondence result does not, by itself, prove that two observations depict the same lunar location. Independent reference data, calibration and ground truth may be required for stronger localization claims.
