CORE PRINCIPLE

A visually convincing match is not automatically ground truth.

Image correspondence answers one question: “Do these observations contain geometrically consistent visual structures?”

Scientific validation asks additional questions: “What is the image?” “Which instrument produced it?” “Where was it acquired?” and “What independent evidence supports that claim?”

JUDGE-READY EXPLANATION
EVIDENCE MODEL

How do we validate an image?

LUNARMATCH does not treat feature similarity alone as scientific validation.

01 Correspondence

Feature descriptors identify candidate visual matches.

02 Geometry

RANSAC tests whether those correspondences support a consistent geometric relationship.

03 Metadata

Mission, instrument and image metadata are inspected independently.

04 Localization

Coordinates are presented only when supported by genuine metadata or legitimate reference/calibration evidence.

```
```
!
IMPORTANT LIMITATION

Validation evidence must be traceable.

If an uploaded image contains no reliable mission metadata, LUNARMATCH will not manufacture an instrument identity, coordinate, projection or ground-truth claim. Such information remains explicitly marked as unavailable or unestablished.
