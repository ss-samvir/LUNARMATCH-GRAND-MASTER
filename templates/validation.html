VALIDATION MODEL

Three layers of evidence.

A visual correspondence score is not automatically geographic ground truth. LunarMatch therefore evaluates three different evidence layers independently.

01
COMPUTATIONAL Feature correspondence, descriptor similarity, reciprocal matching and geometric verification.
02
MISSION METADATA Instrument identity, acquisition information, coordinates, projection, datum and image identifiers.
03
GROUND TRUTH Independent reference coordinates, calibrated products or authoritative mission reference data when available.

VALIDATION RULES

Scientific integrity.

01 NO VISUAL GUESSING

Instrument identity is not assigned merely because an image visually resembles a particular Chandrayaan-2 product.

02 NO FABRICATED COORDINATES

Latitude and longitude remain unavailable when the source image does not provide a legitimate coordinate basis.

03 SCORE ≠ GROUND TRUTH

A strong geometric correspondence demonstrates image-level consistency. It does not by itself establish absolute geographic truth.

04 REFERENCE DATA MATTERS

Independent mission products, calibrated metadata and authoritative reference coordinates can strengthen localization validation.
