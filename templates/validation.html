SCIENTIFIC RULE / 001

Evidence before assumption.

Coordinates are never fabricated. If an image does not contain usable geospatial metadata or an explicit reference sidecar, LUNARMATCH reports the value as Not available.

A correspondence score represents computational evidence. It is not presented as ground-truth accuracy without an appropriate reference dataset.
