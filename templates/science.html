SCIENCE & METHODOLOGY

Behind the correspondence.

LUNARMATCH uses a classical computer-vision pipeline to identify local visual correspondences and test whether those correspondences remain geometrically consistent.

PROCESSING PIPELINE

From pixels to evidence.

Each analysis passes through a sequence of measurable processing stages. The stages are deliberately exposed so the result is not treated as an unexplained black box.

01
INPUT

Image Preparation

Images are decoded, checked and resized when necessary while preserving their usable visual information.

02
ENHANCE

Preprocessing

Grayscale conversion, local contrast enhancement and controlled smoothing prepare the images for feature extraction.

03
DETECT

SIFT Features

Scale-Invariant Feature Transform identifies local keypoints and descriptors that can be compared between observations.

04
MATCH

Descriptor Matching

Feature descriptors are compared using a brute-force L2-distance matcher and candidate correspondences are filtered using the Lowe ratio.

05
VERIFY

Homography + RANSAC

Candidate correspondences are used to estimate a geometric transformation. RANSAC reduces the influence of outlier matches and identifies geometrically consistent inliers.

06
EVIDENCE

Evidence Scoring

Correspondence, geometric consistency, inlier count and image quality are combined into a transparent evidence score.

07
VALIDATE

Metadata Inspection

Available EXIF and related metadata are inspected separately for coordinates, acquisition details, instrument information, mission information and projection data.

FEATURE EXTRACTION

Why use SIFT?

01
◈

Scale Awareness

SIFT descriptors are designed to remain useful across changes in image scale, making them suitable for correspondence tasks where observations may not have identical dimensions.

02
⌁

Local Features

Instead of comparing an entire image as one object, SIFT represents local structures that can be matched independently.

03
◎

Descriptor-Based

Each detected keypoint is represented by a descriptor, allowing candidate correspondences to be evaluated numerically.

MATCHING

From candidate matches to reliable matches.

A descriptor matcher can produce many candidate correspondences, including incorrect ones. LUNARMATCH therefore does not treat every descriptor match as evidence of the same location.

The Lowe ratio test compares the best descriptor distance with the second-best candidate. This helps reject ambiguous matches before geometric verification.

GEOMETRY

Why RANSAC matters.

Even after descriptor filtering, some correspondences may still be incorrect. A geometric transformation is estimated from the candidate correspondences.

RANSAC repeatedly considers subsets of the available correspondences and identifies a model supported by a consistent group of points. These supporting points are treated as inliers.

Key measurement

Inlier count and inlier ratio provide important evidence about whether the candidate matches can be explained by a common geometric relationship.

EVIDENCE MODEL

A transparent score—not a probability.

LUNARMATCH combines several measurable components into an evidence score. This helps summarize the result while keeping the underlying measurements visible.

CORRESPONDENCE 25% Candidate correspondence evidence
GEOMETRIC CONSISTENCY 40% RANSAC / geometric support
INLIER COUNT 20% Number of supporting matches
IMAGE QUALITY 15% Input quality contribution
Important

The resulting score is not calibrated as a probability of image identity. It is an evidence summary intended to be interpreted alongside the underlying measurements.

INPUT QUALITY

Poor input can create poor evidence.

LUNARMATCH evaluates basic image characteristics so that correspondence results can be interpreted in the context of image quality.

01

Contrast

Low contrast can reduce the distinction between local structures and make feature extraction more difficult.

02

Sharpness

Excessive blur can remove local structure and reduce the number of useful keypoints and descriptors.

03

Brightness

Extremely dark or bright inputs can reduce usable image information and affect correspondence quality.

PROVENANCE

Metadata is a separate evidence layer.

Visual correspondence and metadata answer different questions. A strong image match does not establish where an image was captured or which instrument produced it.

When available, metadata may provide additional evidence such as coordinates, acquisition time, camera information, mission information and projection details.

Missing metadata is reported as unavailable rather than reconstructed or invented.

CURRENT LIMITATIONS

Where the system stops.

No fabricated coordinates

The current system does not generate lunar latitude and longitude when genuine coordinate evidence is unavailable.

No visual instrument claim

OHRC, TMC or IIRS identity is not inferred merely from image appearance.

No independent lunar catalogue

The current engine does not independently query a calibrated mission reference database.

No universal ground truth

Synthetic stress tests demonstrate robustness under controlled perturbations but do not replace validation against independent mission data.

RESEARCH DIRECTION

Toward stronger planetary localization.

Future development can integrate calibrated planetary coordinate systems, trusted mission reference catalogues, orthorectified imagery, independent ground truth and reproducible benchmark datasets.

These are research extensions—not capabilities that the current engine claims to already provide.
