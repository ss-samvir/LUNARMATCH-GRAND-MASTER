ABOUT LUNARMATCH

A research-oriented platform for lunar image correspondence.

LUNARMATCH is designed to help users compare lunar imagery, investigate visual correspondence, examine geometric consistency, and inspect available image metadata through an explainable workflow.

◈

Our Objective

Build an accessible computational platform that demonstrates how computer vision can assist in comparing lunar observations while keeping the evidence behind each result visible.

⌁

Explainable Analysis

Instead of presenting only a final similarity number, LUNARMATCH exposes feature counts, candidate matches, geometric inliers, image quality and validation evidence.

◎

Scientific Caution

The platform distinguishes computational correspondence from mission metadata, reference evidence and genuine coordinate information. Unsupported information is not presented as fact.

MISSION CONTEXT

Built around planetary vision.

Lunar imagery can contain repeated textures, illumination changes, shadows and large variations in viewing conditions. These factors make correspondence analysis an interesting computer-vision problem.

THE PROBLEM

Finding meaningful visual correspondence

Two images of a lunar surface may represent related terrain while differing in scale, rotation, illumination, contrast or viewpoint. A useful system therefore needs more than simple pixel comparison.

  • Local feature extraction
  • Feature-to-feature correspondence
  • Geometric consistency checking
  • Outlier rejection
  • Evidence visualization
THE APPROACH

Computer vision + validation

LUNARMATCH combines feature-based image analysis with geometric verification and metadata inspection. The result is intended to be understandable to both general users and technically oriented researchers.

  • SIFT-based local features
  • Lowe-ratio filtering
  • Homography estimation
  • RANSAC-based verification
  • Metadata-aware validation
MISSION IMAGERY

OHRC · TMC · IIRS

These instruments are relevant to lunar remote-sensing discussions. LUNARMATCH does not automatically claim that an uploaded image belongs to a particular instrument unless supporting metadata or reference evidence establishes it.

O

OHRC

Orbiter High Resolution Camera. High-resolution lunar imagery can provide detailed surface information useful for visual correspondence studies.

T

TMC

Terrain Mapping Camera. Terrain-oriented imagery provides an important context for studying lunar surface geometry and mapping-related applications.

I

IIRS

Imaging Infrared Spectrometer. Spectral information can provide scientific context beyond ordinary visible-image correspondence.

WHAT MAKES IT DIFFERENT

Evidence before assumption.

01

Correspondence

Local image features are compared to identify candidate visual relationships between observations.

02

Geometry

RANSAC and homography estimation test whether the correspondence follows a consistent geometric relationship.

03

Validation

Available metadata and reference information are examined separately from the computer-vision result.

04

Localization

Coordinates are displayed only when legitimate coordinate information is actually available. The system does not manufacture latitude or longitude.
