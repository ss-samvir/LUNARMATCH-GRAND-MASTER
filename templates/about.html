Reading the Moon through evidence.

LunarMatch is a research-oriented prototype for lunar image correspondence, geometric verification, localization evidence and scientific validation.

THE PROBLEM

Where was this lunar terrain observed?

Lunar missions generate large volumes of imagery. Comparing observations can reveal whether two images contain consistent terrain structures, but visual similarity alone is not sufficient to establish geographic ground truth.

LunarMatch explores a transparent workflow in which image correspondence, geometric consistency and mission metadata are treated as separate evidence channels.

SCIENTIFIC SCOPE

What the system can establish.

✓ SUPPORTED EVIDENCE
  • Measurable local feature correspondences.
  • Candidate and verified match counts.
  • Geometric consistency estimates.
  • RANSAC inlier evidence.
  • Spatial feature coverage.
  • Available image-quality measurements.
  • Embedded or supplied mission metadata.
! REQUIRES INDEPENDENT EVIDENCE
  • Absolute geographic ground truth.
  • Instrument identity without metadata.
  • Exact latitude and longitude without a valid coordinate basis.
  • Mission attribution based only on visual appearance.
  • Scientific conclusions beyond the available reference data.
MISSION DATA CONTEXT

Chandrayaan-2 instrument context.

OHRC

Orbiter High Resolution Camera

LunarMatch can record OHRC as an instrument identity when the image metadata or another legitimate reference source establishes it.

IDENTITY MUST BE EVIDENCE-BASED
TMC

Terrain Mapping Camera

TMC-related imagery can be incorporated into the validation workflow when corresponding mission/reference evidence is available.

REFERENCE DATA REQUIRED
IIRS

Imaging Infrared Spectrometer

Spectral observations represent a different information modality. LunarMatch therefore avoids identifying an ordinary RGB image as IIRS without supporting evidence.

CURRENT LIMITATIONS

Honest science.

01 REFERENCE DATA DEPENDENCY

Absolute localization requires an appropriate reference source or calibrated spatial metadata.

02 IMAGE MODALITY

Different sensors and spectral modalities may require specialized preprocessing and validation.

03 VISUAL AMBIGUITY

Repetitive lunar terrain can produce visually plausible but incorrect candidate matches. Geometric verification helps reduce this risk.

04 PROTOTYPE STATUS

The platform is intended as a research and hackathon prototype rather than an operational spacecraft-navigation system.
